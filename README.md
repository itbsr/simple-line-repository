# Simple LINE Repository

LINEのトーク履歴としてコピー&ペーストしたテキストをパースし、SQLiteに保存・検索できるCLIツール。

## 背景 / 目的

LINEアプリのトーク画面でメッセージ範囲を選択してコピーしたテキストをターミナルに貼り付けると、発言日時・発言者・本文を構造化して保存する。過去に取り込んだ履歴と日時・発言者・本文が完全に一致するメッセージは重複として無視するため、範囲が重なるトーク履歴を何度貼り付けても安全（べき等）に取り込める。

## 特徴（設計）

- 日付見出し・メッセージ開始行のフォーマット（`YYYY.MM.DD Weekday` / `HH:MM <発言者名> <本文>`）はパーサー内の定数として固定。JSON設定ファイルでは、会話ごとに変わる「参加者一覧」のみを指定する。
- 行が時刻プレフィックスにマッチしても、その直後が設定ファイルの参加者一覧のいずれの名前でも始まらない場合は新規メッセージとみなさず、直前メッセージへの継続行として扱う（誤検出防止）。
- パース結果はSQLiteに保存し、`(timestamp, username, content)` のハッシュで重複を排除する。
- 保存済み履歴を発言者・期間・キーワードで検索して取り出せる。

## 想定する入力フォーマット例

```
2026.06.01 Monday
09:00 田中太郎 会社のご案内です。

以下の通りご確認ください。
・日時：6/10 10:00
09:10 自分 承知しました
```

- 日付見出し行: `YYYY.MM.DD Weekday`（英語の曜日名）
- メッセージ開始行: `HH:MM <発言者名> <本文>`（区切りは半角スペース）。時・分は必ず0埋め2桁（`09:05`）である前提で、`9:05`のような1桁表記は確認できたLINEデータでは一度も出現しなかった。1桁表記が来た場合はヘッダー行として認識されず、位置によってはパース全体が拒否される。
- 上記の場合、`09:00`から始まるメッセージは4行分（1行目の本文＋空行＋2行分の本文）がまとめて保存される。

### パースの構文規則

- 日付見出し行の形（`YYYY.MM.DD Weekday`）にマッチしても、直後の行（または貼り付けテキストの末尾）が「メッセージ開始行」の形でない限り、本物の日付見出し行として確定させない。本文中に日付見出し行と同じ形の文言（引用した日程など）が含まれていても、後続行がメッセージ開始行でなければ単なる継続行として扱われる。
- 確定した日付見出し行同士は時系列で後退できない。直前に確定した日付より前の日付が来た場合はエラーとしてパース全体を拒否する（前進方向の日付ジャンプは、実際の会話でも数日空くことがあるため許容する。本文中の引用日付が前進方向にたまたま曜日まで一致し、かつ直後の行までメッセージ開始行の形をしている場合は検知できない既知の限界）。
- 貼り付けテキストの1行目が、メッセージ開始行でも確定した日付見出し行でもない場合はパース全体を拒否する。それ以外の位置で、確定したヘッダーにも該当せず、かつ継続する先のメッセージも無い行が現れた場合も同様に拒否する（部分的に取り込み可能でも取り込まない）。
- メッセージ開始行より前に確定した日付見出し行が一度も現れていない場合、そのメッセージは「日付未確定」として扱われる。ストレージ層は `(時刻, 発言者名, 本文)` のハッシュで既存のDBを検索し、一致すれば既知のメッセージとしてスキップ、一致しなければインポート全体をエラーとする。

## 設定ファイル例 (config.json)

```json
{
  "participants": ["自分", "田中太郎"],
  "timezone": 9
}
```

- `participants`: 発言者として認識する名前の一覧。時刻プレフィックスの直後がこの一覧のいずれかの名前＋区切り文字で始まる行だけを新規メッセージの開始とみなす。
- `timezone`: 保存するタイムスタンプのUTCオフセット（時間単位、例: `9` = JST）。省略時は `9` として扱う。IANAタイムゾーン名（`Asia/Tokyo`など）は解決コストがかかるため使わない。

設定例は `config/example.config.json` を参照。日付見出し・メッセージ開始行の正規表現自体は現状1種類のフォーマットしか確認されていないため設定化せず、`src/parser.ts` 内の定数として持つ。将来的に異なるフォーマットへの対応が必要になった場合はコードを変更する。

## 想定コマンド（実装予定）

```
repoline import --config config.json < paste.txt
repoline search --user 田中太郎 --from 2026-07-01 --to 2026-07-14
```

- ストレージ: SQLite
