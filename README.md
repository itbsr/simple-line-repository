# Simple LINE Repository

LINEのトーク履歴としてコピー&ペーストしたテキストをパースし、SQLiteに保存・検索できるCLIツール。

## 背景 / 目的

LINEアプリの「トーク履歴を送信」等でエクスポートしたテキストをターミナルに貼り付けると、発言日時・発言者・本文を構造化して保存する。過去に取り込んだ履歴と日時・発言者・本文が完全に一致するメッセージは重複として無視するため、範囲が重なるトーク履歴を何度貼り付けても安全（べき等）に取り込める。

## 特徴（設計）

- JSON設定ファイルで「参加者一覧」「日付見出しの正規表現」「メッセージ行の正規表現」を指定し、貼り付けテキストのフォーマット差異に対応する。
- メッセージ行の正規表現にマッチしても、キャプチャした発言者名が設定ファイルの参加者一覧に含まれない場合は新規メッセージとみなさず、直前メッセージへの継続行として扱う（誤検出防止）。
- パース結果はSQLiteに保存し、`(timestamp, username, content)` の組み合わせで重複を排除する。
- 保存済み履歴を発言者・期間・キーワードで検索して取り出せる。

## 想定する入力フォーマット例

```
[LINEのトーク履歴]
保存日時：2026/07/14 20:30

2026/07/14(火)
20:15	田中太郎	こんにちは
20:16	自分	お疲れ様です
20:17	田中太郎	今日の件ですが
了解です
よろしくお願いします
```

上記の場合、`20:17`から始まるメッセージは3行分（「今日の件ですが」「了解です」「よろしくお願いします」）が本文としてまとめて保存される。

## 設定ファイル例 (config.json)

```json
{
  "participants": ["自分", "田中太郎"],
  "dateHeaderPattern": "^(?<year>\\d{4})/(?<month>\\d{1,2})/(?<day>\\d{1,2})\\(.+?\\)$",
  "messageLinePattern": "^(?<hour>\\d{1,2}):(?<minute>\\d{2})\\t(?<user>.+?)\\t(?<content>.*)$",
  "timezone": "Asia/Tokyo"
}
```

- `participants`: 発言者として認識する名前の一覧。この一覧に含まれる名前がキャプチャされた行だけを新規メッセージの開始とみなす。
- `dateHeaderPattern` / `messageLinePattern`: 名前付きキャプチャグループ (`year`/`month`/`day`, `hour`/`minute`/`user`/`content`) を使った正規表現。貼り付けテキストのフォーマットが変わった場合はここを調整する。
- `timezone`: 保存するタイムスタンプのタイムゾーン（デフォルト `Asia/Tokyo`）。

## 想定コマンド（実装予定）

```
repoline import --config config.json < paste.txt
repoline search --user 田中太郎 --from 2026-07-01 --to 2026-07-14
```
